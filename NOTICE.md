# Notice

**KiCad-Ai-Agent** is a derivative of
[mixelpixx/KiCAD-MCP-Server](https://github.com/mixelpixx/KiCAD-MCP-Server),
an MCP (Model Context Protocol) server that lets an AI agent (e.g. Claude)
drive KiCad's schematic and PCB editing through tool calls.

All credit for the original architecture, the 146 MCP tools, and the
extensive test suite belongs to the upstream project and its contributors.
This fork exists to package, document, and extend that work as an
end-to-end "describe a circuit in plain text, get a schematic, a routed
PCB layout, and manufacturing files" open-source agent — see `PLAN.md`
for the roadmap.

Both projects are licensed MIT (see `LICENSE`). Changes made in this fork
are tracked in git history and, where practical, will be contributed back
upstream.

Upstream repository: https://github.com/mixelpixx/KiCAD-MCP-Server
This repository: https://github.com/manoj020218/KiCad-Ai-Agent
